# For any Claude working in this repository

Read `README.md` first. It explains how this studio works and the rules every chat follows.

- **You're a game's chat:** read `START-MESSAGE.md`, then `direction/START_HERE.md`, then `games/<your-slug>/ROUND.md`. Work only in `games/<your-slug>/`, on a branch `<slug>/round-<n>`, and open a pull request.
- **You're the design chat:** you own `direction/` and `games/*/reviews/`. Review pull requests against `direction/DIRECTION.md`. Log every result in the vault's `programmes/publish-skill/NOTES.md`.

Never put a secret in this repository.
